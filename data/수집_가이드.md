# 데이터 수집 가이드

> 가설 검증 정밀도를 높이기 위한 데이터 수집 방법.
> 기존 메타 비즈니스/유튜브 CSV 내보내기 + 아래 수동 기록을 병행한다.

---

## 왜 추가 수집이 필요한가

메타 비즈니스 CSV는 **일별 합산** 데이터만 제공한다.
→ "3/27에 도달 104" 는 알 수 있지만, "어떤 게시물이 104를 만들었는지"는 모른다.
→ 같은 날 릴스와 피드를 둘 다 올리면 어느 쪽이 성과를 냈는지 분리 불가.

**게시물별 인사이트**를 기록하면 이 문제가 해결된다.

---

## 수집 항목

### 1. 기존 유지: 플랫폼 CSV 내보내기 (주 1회)

| 플랫폼 | 경로 | 주기 | 저장 위치 |
|--------|------|------|-----------|
| 유튜브 | YouTube Studio → 분석 → 고급 모드 → 내보내기 | 매주 일요일 | data/유튜브/YYYY-MM-DD_YYYY-MM-DD/ |
| 인스타 | Meta Business Suite → 인사이트 → 내보내기 | 매주 일요일 | data/인스타/YYYY-MM-DD_YYYY-MM-DD/ |

유튜브 CSV는 영상별 성과(조회수, CTR, 평균 조회율, 구독자 등)가 이미 분리되어 있으므로 추가 수동 기록 불필요.

### 2. 신규 추가: 인스타 게시물별 인사이트 (게시 후 3일 뒤 1회)

인스타 콘텐츠를 올리고 **3일 뒤**에 아래 정보를 기록한다.
(3일 = 알고리즘 2차 푸시까지 반영되는 시점)

**기록 파일**: `data/게시물별/posts_log.csv` (인스타 전용)

**기록 방법**:
1. 해당 게시물 터치 → "인사이트 보기"
2. 아래 CSV 항목에 맞춰 한 줄 추가

**CSV 컬럼 설명**:

| 컬럼 | 설명 | 확인 위치 |
|------|------|-----------|
| 게시일 | 콘텐츠 업로드 날짜 | - |
| 기록일 | 인사이트 확인 날짜 (게시 후 3일 뒤) | - |
| 포맷 | 릴스 / 피드 / 스토리 / 캐러셀 | - |
| 제목 | 캡션 첫 줄 또는 내용 요약 | - |
| 캐릭터 | 등장 캐릭터 (예: 로지+퍼지) | - |
| 업로드시간 | 대략적 업로드 시간 (예: 18:00) | - |
| 검증가설 | 이 콘텐츠로 테스트하는 가설 ID (예: H-07) | hypothesis_ledger.md 참고 |
| 도달 | 도달한 계정 수 | 인사이트 → 도달한 계정 |
| 조회수 | 총 조회수 (릴스) 또는 노출수 (피드) | 인사이트 → 조회수/노출 |
| 좋아요 | 좋아요 수 | 인사이트 → 좋아요 |
| 댓글 | 댓글 수 | 인사이트 → 댓글 |
| 저장 | 저장 수 | 인사이트 → 저장 |
| 공유 | 공유 수 | 인사이트 → 공유 |
| 팔로우 | 이 게시물에서 발생한 팔로우 수 | 인사이트 → 팔로우 (있는 경우만) |
| 비고 | 특이사항 메모 | - |

---

## 기록 시 팁

- **게시 직후가 아니라 3일 뒤에 기록**하는 게 핵심. 초기 수치는 불안정함
- 7일 뒤에 한 번 더 기록하면 롱테일 효과까지 볼 수 있지만, 부담되면 3일 1회로 충분
- 숫자가 정확하지 않아도 괜찮다. "대략 이 정도"만 기록해도 일별 합산보다 100배 유용
- 업로드 시간은 **매번 같은 시간대로 고정**하면 시간 변수를 통제할 수 있음 (예: 항상 오후 6시)
- 유튜브는 기록 안 해도 됨 -- CSV에 영상별 데이터가 이미 다 있음
