### 2. 핵심 발견: 5초 vs 13초 숏폼의 구조적 차이

이번 W14 데이터에서 가장 중요한 발견: **같은 숏폼이라도 성과가 11배 차이**남.

| 비교 항목 | 로지+퍼지 얹기 (3/27) | 입단테스트 (4/3) | 차이 |
|-----------|----------------------|-----------------|------|
| 길이 | 5초 | 13초 | 2.6배 |
| 유튜브 조회수 | 3,403 | 312 | **10.9배** |
| 평균 조회율 | 211% | 88% | 2.4배 |
| 노출 CTR | 32.35% | 15.15% | 2.1배 |
| 인스타 도달 | 104 | 122 | 비슷 |
| Day 3 리바운드 강도 | 12.3배 (190→2331) | 1.56배 (89→139) | **7.9배** |
| 구독자 전환 | +2 | 0 | - |

**원인 분석 (바이블 기반):**

| 요인 | 로지+퍼지 얹기 | 입단테스트 | 영향 |
|------|---------------|-----------|------|
| **루프 가능성** | 5초 → 무한 반복 자연스러움 (조회율 211% = 2바퀴+) | 13초 → 한번 보고 답 확인하면 끝 | 조회수 차이의 주요 원인 |
| **캐릭터 관계 활용** | 퍼지→로지 "의존과 배려" 관계 패턴 직접 구현 | 전체 캐릭터 등장하나 관계성 없음 (찾기 게임) | 감정적 훅 유무 |
| **콘텐츠 유형** | 감정/관계 기반 (캐릭터 매력) | 참여형 (인지적 과제) | 반복 시청 동기 차이 |
| **썸네일/제목** | 캐릭터 이모지 + 행동 암시 | 텍스트 중심 + 찾기 챌린지 | CTR 2배 차이 |

**핵심 결론:**
- 숏폼의 성공 공식 = **짧은 길이(5초) + 캐릭터 관계 패턴 + 루프 가능 구조**
- 참여형 콘텐츠(찾기/퀴즈)는 인스타에서는 비슷한 도달을 얻지만, 유튜브에서 루프가 안 되어 조회수 폭발이 없음
- 이 발견은 plan_26W15의 숏폼 A(로지+퍼지 갭 모에, 5~7초) 방향이 맞다는 것을 뒷받침

### 4. 데이터 특이점

#### 특이점 A: 입단테스트의 "Day 3 미니 리바운드"

```
Day 0 (4/2): 조회율 89% — 초기 노출
Day 1 (4/3): 조회율 70% — 하락
Day 2 (4/4): 조회율 34% — 급감 (디프)
Day 3 (4/5): 조회율 139% — 리바운드!
```

로지+퍼지(Day 3에 2331%)보다 규모는 훨씬 작지만, **Day 2 디프 → Day 3 리바운드** 패턴 자체는 재현됨. 이 패턴이 유튜브 Shorts 알고리즘의 일반적 특성인지, 콘텐츠 품질에 따라 증폭되는 것인지 추가 데이터 필요.

동시에 인스타에서도 4/5에 방문 4건 발생 (4/3~4/4는 방문 0~1). 유튜브 Day 3와 인스타 재방문이 동기화되는 현상이 2번째 관찰됨.

#### 특이점 B: 굿즈 릴스의 도달력

PC배경 릴스(3/30)가 도달 115를 기록. 이건 "로지+퍼지 얹기"와 같은 날(3/30)에 올라간 것이라 로지+퍼지의 Day 3 2차 푸시 효과를 등에 업었을 가능성 높음. 하지만 굿즈 릴스도 릴스 포맷이면 100+ 도달이 가능하다는 데이터 포인트.
