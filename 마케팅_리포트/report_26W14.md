### H-02 수정 상세: "감소"가 아닌 "가속" 곡선

기존 가정: 업로드 후 2~3일에 걸쳐 도달이 **점차 줄어든다**
실제 데이터:

```
[유튜브 "로지+퍼지" 일별 시청 시간]
Day 0 (3/27): 0:00:09  ← 업로드일
Day 1 (3/28): 0:00:08  ← 비슷
Day 2 (3/29): 0:00:22  ← 2.5배 점프
Day 3 (3/30): 0:01:56  ← 5배 점프 (116초!)

[인스타그램 일별 도달]
Day 0 (3/27): 104  ← 1차 피크
Day 1 (3/28): 1    ← 급감
Day 2 (3/29): 0    ← 0 (BUT 상호작용 7, 프로필 방문 8!)
Day 3 (3/30): 112  ← 2차 피크 (1차보다 높음!)
```

**수정된 모델: 3단계 도달 사이클**

| 단계 | 시점 | 현상 | 해석 |
|------|------|------|------|
| 1단계: 초기 노출 | Day 0 | 높은 도달, 낮은 상호작용 | 알고리즘이 신규 콘텐츠를 테스트 배포 |
| 2단계: 재방문 인게이지먼트 | Day 1~2 | 도달 급감, 상호작용+프로필 방문 급증 | Day 0에서 본 사람들이 돌아와서 반응 |
| 3단계: 알고리즘 2차 푸시 | Day 3 | 도달 재폭발 (1차 이상) | 2단계의 인게이지먼트 신호를 학습한 알고리즘이 새로운 오디언스에 확장 배포 |

이 3단계 모델이 맞다면, **2단계를 인위적으로 강화**하면 3단계의 2차 푸시가 더 강해질 수 있다. → 신규 가설 H-06으로 연결.

## 2. 데이터 특이점 발견

### 특이점 A: 3/29 "재방문 폭발"

| 지표 | 3/29 수치 | 의미 |
|------|-----------|------|
| 인스타 신규 도달 | **0** | 새 사람은 안 왔음 |
| 인스타 상호작용 | **7** | 이전에 본 사람들이 돌아와서 반응 |
| 인스타 프로필 방문 | **8** | "이 계정 뭐하는 곳이지?" 탐색 행동 |
| 유튜브 숏폼 시청 | **22초** (전일 8초 대비 2.5배) | 유튜브에서도 같은 사람들이 다시 봄 |

**해석**: 3/27에 콘텐츠를 발견한 사람들이 2일 뒤 **양 플랫폼을 동시에 재방문**했다. 이 재방문 행동이 다음 날(3/30)의 알고리즘 2차 푸시를 트리거한 것으로 추정.

### 특이점 B: 에디슨 편의 "딥 뷰잉" 롱테일

| 날짜 | 업로드 후 | 시청 시간 | 해석 |
|------|-----------|-----------|------|
| 3/19 | Day 0 | 0:00:13 | 업로드일 짧은 시청 |
| 3/24 | Day 5 | **0:02:20** | 135초 영상을 거의 완주 (104%) |
| 3/26 | Day 7 | **0:01:30** | 다시 67% 시청 |
| 3/29 | Day 10 | 0:00:07 | 짧은 재확인 |

**해석**: 숏폼에서 유입된 1~2명이 채널을 탐색하며 긴 영상을 **반복 깊게 시청**했다. 에디슨 편의 평균 조회율 52.5%는 이 패턴의 결과. **숏폼이 긴 영상의 발견 채널 역할**을 한다는 증거.

### 특이점 C: 3/26 "채널 빈지" 현상

3/26(숏폼 업로드 하루 전)에 모든 영상이 동시 시청됨:

| 영상 | 3/26 시청 시간 |
|------|----------------|
| 놀러가자 | 0:00:39 |
| 에디슨 편 | 0:01:30 |
| 퀘스터즈 출발 | 0:00:22 |

**해석**: 한 명(또는 소수)이 채널의 기존 콘텐츠를 **한꺼번에 몰아서** 시청. 이 행동이 다음 날(3/27) 숏폼 업로드의 알고리즘 초기 배포를 도왔을 가능성 있음 (채널 활성도 신호).

### 특이점 D: 인스타 참여율의 스케일 반비례

| 도달 규모 | 날짜 (예시) | 참여율 |
|-----------|-------------|--------|
| 극소 (1~4) | 3/10, 3/19, 3/26 | 50~400% |
| 소규모 (11) | 3/20 | 18.2% |
| 중규모 (104) | 3/27 | 0.0% |
| 대규모 (112) | 3/30 | 5.4% |

**해석**: 도달이 커지면 참여율은 자연 하락. 하지만 3/30의 5.4%도 업계 평균(3~6%)의 상단. 대규모 도달에서도 참여율이 유지된다는 건 콘텐츠 자체의 인게이지먼트 파워가 있다는 뜻.

### "로지 위에 퍼지 얹기" 성공을 캐릭터 바이블로 해부

바이블의 퍼지→로지 관계 패턴:
> "퍼지가 괴롭힘/장난침 → 로지가 묵묵히 받아줌 → 위기 때 로지가 구해줌 → 퍼지 조용해지며 달라붙음"

이 숏폼은 이 패턴의 **첫 2단계**("장난침 → 받아줌")를 5초에 압축한 것.

**아직 숏폼에 안 쓴 캐릭터 자산들:**

| 자산 | 바이블 근거 | 숏폼 포맷 가능성 |
|------|-------------|------------------|
| 퍼지 갭 모에 | "로지의 진심 어린 배려 앞에서 잠시 조용해지며 동글동글해짐" | 5초 내 감정 반전 → 반복 시청 유도 (높음) |
| 매티 체념 리액션 | "한숨+체념 → 피식 웃거나 고개 절레절레" | 마지막 프레임 서프라이즈 (높음) |
| 파이+퍼지 동시 사고 | "같이 뛰어다님 → 같이 사고침 → 같이 혼남" | 코미디 숏폼 (높음) |
| 매티 미식가 모드 | "음식에 관해선 눈이 반짝임, 잔소리도 멈춤" | 갭 모에 숏폼 (중간) |
| 파이 위기 리더십 | "진짜 위기 순간에만 어른스러워짐" | 감동형 숏폼 (낮음 - 5초에 감동 어려움) |
