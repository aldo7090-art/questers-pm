## W19 주요 경고

- 5/6·5/7 권고 14개 + 5/8 모닝 권고 9개 = 23개 항목 진행 여부 미반영. W19 절반이 비공개 상태.
- 4/26 마감 자산 5종(캐릭터 시트 / 컬러 가이드 / 브랜드 카드 / 메모지 / 키링) D+12. 점검 자체에 10분이지만 12일째 미실행.
- 어버이날 D-day. 5월 가정의 달 첫 시즌 — 미게시 시 통째 손실. 골든타임 잔여 한정.
- 넥스페리움 5/9 D-1 — 브랜드 카드 + 1차시 디렉팅 + 인쇄 발주 + 키트 셋업 4단계 모두 오늘 처리 필수.
- 트라이탄 보틀 견적 D-1 — 5/16 발주 마감 직전 단계. 메일 1통이 5/16 배포 전체 운명을 결정.
- 인스타 토큰 6주째 방치. W15~W19 전체 데이터 소실 진행 중. H-03 가설 영구 폐기 직전.
- 팝업 결과 1차 D+7, 2차 D+3 — 기억 휘발 임계점. 오늘 메모 못 잡으면 영구 소실.
- W19 릴스 업로드 여부 미확인. 미업로드면 5/8 유튜브 숏츠 재활용 자체 불가.

## PDCA Act 액션 정리

- **팝업 1차+2차** — Check 미수행 → 메모 수준이라도 W20 첫주 착수. 미수행 시 가설 자체 폐기.
- **H-07 퍼지 갭 모에** — 6주+ 미실행 → W20에서 폐기/변경 결정. 더 이상 이월 금지.
- **인스타 토큰 갱신** — 6주째 방치 → W20 첫주에 처리 못 하면 H-03 자체 폐기. 측정 불가능한 가설은 의미 없음.
- **5월 가정의 달 다중 컨셉** — 어버이날 미게시면 4종 중 2종(어린이날 팝업+어버이날) 시즌 통째 손실 → 스승의날·소풍은 컨셉 결정만 즉시.
- **넥스페리움 키트 스토리텔링** — 5/9 수업 후 학부모/아이 반응 수집 → 2~6차시 디렉팅 톤 결정의 핵심 데이터.
- **캐릭터 바이블 W19 착수** → W20으로 1주 더 이월. W20 못 시작하면 라이선싱·AI 콘텐츠 전체 일정 도미노 지연.
